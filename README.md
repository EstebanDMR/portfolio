# Portafolio de Esteban Mercado Rachath

Portafolio bilingüe de Esteban Mercado Rachath, estudiante de Ingeniería de Sistemas en etapa final y candidato a Desarrollador de Software Junior. Presenta proyectos de desarrollo web, backend, bases de datos y algoritmos.

## Desarrollo local

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm run build
```

## Publicación en Vercel

Importa este repositorio en Vercel como proyecto **Vite**. El comando de compilación es `npm run build` y el directorio de salida es `dist`. El sitio no requiere variables de entorno para compilarse.

El botón CV descarga el PDF incluido en `public/cv-esteban-mercado.pdf`. Los enlaces de contacto y proyectos están definidos en `src/data/profile.ts` y `src/data/projects.ts`; las versiones en inglés se encuentran en `src/data/translations.ts`.
